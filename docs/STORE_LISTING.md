## Detailed Description (EN)
**Gecko for Antigravity** is an independent companion extension for Antigravity (not affiliated with or endorsed by Google). It brings Antigravity into your Chrome Side Panel and connects Chrome as a live remote arm for Antigravity App, IDE, CLI, and Python SDK via a secure local companion.

**Key Features**
- **Live Browser Automation with Visual Feedback**: Ask Gecko to click links/emails, fill forms, select options, scroll pages, or manage tabs. A smooth virtual cursor and click ripple show every action clearly in real time.
- **Fast Multi-Step Execution**: Initial page snapshot + multi-tool batching + automatic rolling history compression keep multi-step tasks fast and accurate.
- **Remote Arm for Antigravity App/IDE (MCP)**: Execute browser actions directly from Antigravity App or IDE through an authenticated loopback (`127.0.0.1`) relay.
- **Multi-Model Selector & Right-Click Ask**: Switch AI models right from the chat bar, or right-click any page/selection and choose **Hỏi Gecko for Antigravity**.
- **One-Time Permission & Built-in Safety**: Uses optional host permissions (revocable anytime). Always blocks password inputs, payment/checkout pages, banking domains, and CAPTCHAs; redacts sensitive tokens before sending.

**Requirements**
- Desktop Chrome 116+ (macOS, Windows, Linux)
- Local companion installed from the companion package + Antigravity CLI (1.5.7+) or Antigravity Python SDK.
